# Ebook Library - Full Stack Project

A complete full-stack ebook library application built using modern web technologies.

## Tech Stack

### Frontend App
- Next.js
- TypeScript
- Tailwind CSS

### Admin Dashboard
- React
- Vite
- TypeScript

### Backend API
- Node.js
- Express.js
- MongoDB

## Features

- User authentication
- Admin dashboard
- Add / edit / delete books
- Search books
- Download books
- Responsive UI
- Protected routes
- File upload support

## Folder Structure

- `elib-API` → Backend API
- `elibApp` → User frontend
- `elibDashboard` → Admin dashboard
